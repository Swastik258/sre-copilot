# Tarn homepage

## Scope and visitor mode
Replace the visual world of the public homepage only. Persuade.

## Audience, job, action, proof, constraints
SRE, platform, and DevOps engineers evaluating a tool during infrastructure investigation. They need a clear read-only diagnosis offer and a way to verify findings against source records. Primary action: start a free account. Secondary action: read the docs. Use the existing workflow, truthful current adapters, wordmark, working links, and public navigation. Do not invent incidents, customers, testimonials, prices, metrics, or live diagnosis screenshots.

## Direction contract
### THESIS
The evidence envelope makes provenance tangible: a finding is only useful when its source can travel with it. Refuse the default split hero with a decorative dashboard preview.

### OWN-WORLD
Build one unmistakable packet from cobalt-blue outer stock, pale carbon-copy inserts, and a high-visibility yellow-orange seal. Use a confident grotesk for the promise, compact machine-readable labels for identifiers, and fold lines, punched tabs, and transfer marks as the component grammar. The envelope and its inserts carry the page structure rather than appearing as a floating illustration.

### STORY
The visitor understands that Tarn performs read-only investigations, sees how source records remain linked while observations and ranked hypotheses stay distinct, and can start free or read the docs. Use only supported integration names and confirmed behavior.

### FIRST VIEWPORT
Place the working public navigation on the packet's top fold. Below it, show one open envelope at a single scale: a legible headline and primary Get started action on its address panel; a secondary docs link and read-only note beside it; three connected, full-size inserts labeled Source records, Observed facts, and Ranked hypotheses emerging from the pocket. The adapter names sit on the envelope's edge, not as badges under the hero.

### FORM
The Evidence Envelope, Impeccable's grounded pick (candidate 2); seed:4b829b1732a0f157. Signature interaction: a keyboard-accessible fold tab traces one continuous source-to-finding path across the inserts while keeping every label readable without motion. Responsive behavior stacks the same inserts in order and keeps the seal and action visible. Code-led; image generation is unavailable in this session.
